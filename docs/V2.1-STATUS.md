## Device inventory implementation checkpoint

Existing bot tool declarations expose `ha_search` with domain/area filters, pagination and `ha_get_state`, but do not yet expose HA area/entity/device registries. Therefore the bot must not claim an exhaustive area inventory or a missing device from a single search. Read-only registry access requires an independently verified connector/tool schema before implementation.

The prompt now retains device type in search terms and counts unavailable/unknown entities as discovered devices (not controllable targets). MCP debug log no longer prints the full list of private entity names and states. Added regression coverage. These changes are on GitHub only until DEV integration testing.
