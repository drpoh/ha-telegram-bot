## Безопасность перемещения

1. Запустить `node scripts/docs/audit-legacy-doc-references.mjs` из корня репозитория: это только чтение `git ls-files`, результаты — файлы и номера строк без вывода секретов.
2. Проверить как относительные Markdown-ссылки, так и явные ссылки на пути в тестах, скриптах и инструкциях; переезд может ломать потребителей даже при успешном Markdown link-check.
3. Обновить потребителей или оставить документ-совместимость по старому пути; не удалять рабочие инструкции без подтверждения.
4. Выполнить `node scripts/docs/check-active-markdown-links.mjs` и `npm test` на GitHub CI. Только затем отдельный PR для перемещения.
5. ADR/стратегические решения не удалять и не переписывать задним числом.
