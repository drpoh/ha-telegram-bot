# Gate E — голосовой интерфейс

**Состояние и дата последней проверки — в [CURRENT-STATE](../CURRENT-STATE.md#3-gates).**

## Критерии

1. Провести реальный цикл `ESPHome/Atom Echo → Assist/Whisper → intent → Policy → HA-MCP → Verify → Piper/TTS`.
2. Для управления устройствами голосовая фраза не может обходить policy/identity/consent; критические команды остаются `CONFIRM`/`DENY`.
3. Подтвердить явное разделение STT/TTS, Telegram, локальной/сетевой авторизации и rollback при ошибке.
4. Проверить ложные пробуждения, таймаут, неверный объект, отмену и отсутствие самопроизвольных физических действий.
5. Переиспользовать Home Assistant Assist, ESPHome, Whisper/Piper и существующие библиотеки; не создавать второй voice framework без необходимости.

## Статус доказательств

Наличие Atom Echo, Whisper, Piper и рабочего HA-MCP чтения само по себе **не доказывает** интегрированный V3 голосовой путь или его принятие.
